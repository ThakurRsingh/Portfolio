# Thakur's Portfolio

Welcome to my personal portfolio website! This project showcases my skills, experience, education, and work through a modern, responsive web application built with React and Vite, styled using Tailwind CSS.

## 🚀 Features
- **About Me**: Brief introduction and background.
- **Skills**: Technologies and tools I am proficient in (React, Node.js, Python, etc.).
- **Experience**: Professional work history and roles.
- **Education**: Academic background and achievements.
- **Work**: Projects and contributions with visual logos.
- **Contact**: Get in touch via email or social links.
- **Responsive Design**: Optimized for all devices.

## 🛠️ Tech Stack
- **Frontend**: React, Vite
- **Styling**: Tailwind CSS, PostCSS
- **Linting**: ESLint

## 📦 Installation & Setup
1. **Clone the repository**
   ```powershell
   git clone https://github.com/ThakurRsingh/Portfolio.git
   cd Thakur-s-Portfolio
   ```
2. **Install dependencies**
   ```powershell
   npm install
   ```
3. **Start the development server**
   ```powershell
   npm run dev
   ```
4. **Open in browser**
   Navigate to `http://localhost:5173` (default Vite port).
